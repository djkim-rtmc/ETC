## 무엇인 프로젝트인가

강원 컨소시엄 **AI 예방접종 돌봄 서비스**. 운영 VD-IMS 자가체크 화면에 의료진 웹의 AI 브리핑·자가체크 결과·예측 대조를 이식한 HTML 프로토타입.

포함:

- 자가체크 목록 / 상세 / 종합 보고서
- 이상반응 레포트 PDF 목업
- 상세 상단 원격진료 요청 목록, 원격진료 진행 버튼 (의료진 웹  ton)
- RWD 8000건 시드 기준 목 데이터

제외: 전자예진 입력·결과, v1/v2 폴더 수정.

상세 범위: `gangwon-tp/docs/범위.md`
