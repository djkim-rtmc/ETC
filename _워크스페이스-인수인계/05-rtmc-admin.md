# rtmc-admin (회사 홈페이지 관리자)

## 현재 경로

`D:\Desktop\서비스기획팀\커서활용\rtmc-admin`  
(예전: `D:\Desktop\서비스기획팀\홈페이지\rtmc-admin`)  
참고만: `서비스기획팀/홈페이지/rtmc-admin-html` 은 예전 HTML 산출물일 수 있음. 이 React 앱과 혼동하지 말 것.

```bash
npm run dev
```

## 무엇인 프로젝트인가

Vite + React 관리자 목업. 실제 API 없이 `src/mock` 시드.

대메뉴 방향(채팅 기준): 홈페이지 / 빔스 / 미란다 / Pv-IMS. 빔스·미란다·핌스는 **나중에 개발**, IA만 잡아 둔 상태일 수 있다.

주요 페이지:

- 로그인, 대시보드, 회사/설치
- 조직 추가, 저널, 자료실, 백신 매뉴얼
- 이상반응 팔로업
- 관리: 사용자, 배너, 팝업, FAQ, 문의, 공지, 약관, 로그

렌더 규칙: 검색 필터·폼·테이블은 입력 하나 바꿀 때 전체가 다시 그려지지 않게 분리·memo.
