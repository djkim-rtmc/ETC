# 워크스페이스 재생성 안내

작성일: 2026-09-09  
목적: 예전 워크스페이스를 지운 뒤 **새 폴더 + 새 채팅**으로 작업을 이어가기 위함.  
제외: 개인 프로젝트(`starlight-footprint-maker`, `washcar` 등)

채팅 기록은 폴더 경로에 묶여 있다. 폴더를 옮기거나 워크스페이스를 지우면 **자동으로 따라오지 않는다.** 이 폴더의 md를 새 채팅 첫 메시지에 붙이면 된다.

## 권장 순서

1. 이 `_워크스페이스-인수인계` 폴더를 USB·다른 드라이브·클라우드에 **먼저 복사**해 둔다.
2. 프로젝트 폴더를 원하는 위치로 정리한다.
3. Cursor Workspaces에서 예전 항목을 지운다. (목록만 숨김. 채팅 원본은 보통 남음)
4. Cursor에서 **File → Open Folder**로 **프로젝트 하나**를 연다.  
   여러 개를 한 창에 묶지 않는 것을 권장한다. 채팅이 프로젝트별로 나뉜다.
5. 새 Agent 채팅을 연다.
6. 해당 프로젝트 md에서 **「신규 채팅 시작 문구」**를 복사해 붙인다.
7. 이어서 할 일만 한 줄로 추가한다.

## 하지 말 것

- `%APPDATA%\Cursor\User\workspaceStorage`를 지우지 않는다. 예전 채팅이 여기에 있다.
- 여러 팀 프로젝트를 하나의 멀티 루트 워크스페이스로 다시 묶지 않는 것이 낫다. 채팅이 섞인다.
- 이 인수인계 md만 지우고 워크스페이스를 지우면, 새 채팅에서 맥락을 복구하기 어렵다.
