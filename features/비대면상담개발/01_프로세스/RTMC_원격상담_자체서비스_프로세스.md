## 1. 전제

1. KOI 제공 비대면 상담과 **별도로**, RTMC가 **자체 비대면 상담**을 운영하는 경우를 가정한다.
2. 현재 v2 확정 방향은 **KOI 서비스 제공**이다. 본 문서는 **로드맵·내부 논의용**이며 개발 착수 전까지 제외한다.
3. 예약·스케줄·확정·화상상담(**상담실**)·상담기록 정리·로컬 다운로드는 **전부 RTMC 내장**이다. (KOI 새 탭 연동 없음)
4. 접종자 식별은 기존과 같이 **RTMC 유저 ID**를 사용한다.
5. UI 용어는 **비대면 상담 / 상담실**을 사용한다. (레거시 파일명은 유지 가능)

## 2. 역할

| 구분 | 담당 |
|---|---|
| 접종자 (유저웹) | 자가체크 · AI Level 확인 · Case A 신청 · 일정 선택 · 당일 상담 입장 · 취소(가능 상태만) |
| 의료진 (VD-IMS) | 자가체크·AI 조회 · Case B 요청 · 예약 확정/예약 취소 · 상담실 진행 · 기록 로컬 다운로드 |
| RTMC 플랫폼 | 상태 관리 · 알림톡 발송 · 스케줄 · 화상(WebRTC 가정) · 전사/SOAP 목업 · 메타 보관 |

## 3. 상태값

목록·유저웹 상태 카드·예약 화면에서 공통으로 쓰는 코드다.

| RTMC 표시 | 의미 |
|---|---|
| 해당없음 | 해당 회차에 비대면 상담 없음 (기본·새 회차 덮어쓰기 시) |
| 상담요청 | Case B — 의료진이 상담 요청 메시지 발송, 접종자 스케줄 미선택 |
| 예약대기 | Case A — 접종자 **신청 완료**(확정 전) · Case B — 스케줄 선택 후 확정 대기 |
| 예약확정 | 의료진 확정. 접속 URL 포함 알림톡 발송. **상담 시작 15분 전**부터 상담실 입장 가능 |
| 상담중 | 상담 시간대 세션 진행 (상담실 입장·화상 상담) |
| 상담완료 | 상담 정상 종료 |
| 상담취소 | 접종자 또는 의료진(예약 취소)에 의해 취소 |
| 상담불참 | 노쇼 |

### 3.1 Case별 확정 전 상태

- **Case A**: 신청 완료 ~ 확정 전 = **예약대기**
- **Case B**: 요청 직후 ~ 스케줄 미선택 = **상담요청** / 스케줄 선택 후 ~ 확정 전 = **예약대기**

### 3.2 회차(1~4차) 모델

| 규칙 | 내용 |
|---|---|
| 목록 1행 | **접종자(접종 건) 단위** 1행 |
| 목록 「비대면 상담」열 | **최신 회차** 상태만 표시. 새 회차 자가체크 시 **해당없음**으로 덮어씀 |
| 상세 · 비대면 상담 탭 | **1~4차 칩**으로 회차별 접수·처리 이력 **유지** |
| 상담 요청 메시지 | **최신 회차**이면서 상태가 **해당없음**일 때만 활성 |
| 자가체크 일시 | 최신 회차 완료 시각 · 목록 최신순 |

## 4. 프로세스

### 4.1 Case A — 접종자 직접 신청

```
[유저웹] 7일 내 자가체크 조건 충족 → 「비대면 상담 신청하기」
    ↓
[유저웹] 의료진 선택 → 일정(시간 슬롯) 선택 → 확인
    ↓
[유저웹] 신청 완료 **페이지** (팝업 아님) → 홈 복귀
    ↓  상태: 예약대기
[유저웹] 상태 카드 노출 (배지 · 일정 · 의료진 · 안내 문구 · 취소)
    ↓
[의료진 · 예약] 상세 확인 → 「예약 확정」→ 예약 확정 메시지 발송
    ↓  상태: 예약확정
[RTMC] 접종자 알림톡 (접속 URL)
    ↓
[RTMC] 당일 1시간 전 리마인드 알림톡 (동일 접속 URL)
    ↓  상태: 상담중 (입장·세션 시작 시)
[상담실] 화상 + 전사/SOAP + 자가체크·AI 참고 → 종료
    ↓  상태: 상담완료
```

- Case A 신청 직후 **예약요청 알림톡은 발송하지 않음**.
- 신청 완료는 **전용 페이지**로 안내한 뒤 홈으로 이동한다.
- 상태 카드 안내 문구 예: 「일정이 확정되면 접속정보가 메시지로 발송됩니다.」

### 4.2 Case B — 의료진 요청

```
[VD-IMS · 상세 · 비대면 상담] 「상담 요청 메시지」 발송
    ↓  상태: 상담요청
[RTMC] 접종자 알림톡 (예약·일정 선택 URL)
    ↓
[유저웹] 해당 의료진 가용 스케줄만 선택 → 신청
    ↓  상태: 예약대기
[의료진 · 예약] 「예약 확정」→ 예약 확정 메시지 발송
    ↓  상태: 예약확정
이후 Case A와 동일
  (확정 알림톡 → 1시간 전 리마인드 → 상담실 → 상담완료)
```

- 의료진의 **요청 액션은 VD-IMS에서만** 수행한다.

### 4.3 접종자 취소

| 가능 상태 | 불가 상태 |
|---|---|
| 예약대기 · 예약확정 등 (목업: 상태 카드에 취소 노출) | **상담중** — 취소 없음, **입장만** |

```
[유저웹] 상태 카드 「취소」→ 확인 모달 (취소하기 | 닫기)
    ↓  상태: 상담취소
```

### 4.4 의료진 예약 취소

예약 상세에서 확정 전(예: **예약대기**) 건에 대해 의료진이 일정을 취소할 수 있다.

```
[예약 상세] 「예약 취소」
    ↓
[예약 취소 메시지] 접종자 대상 알림톡 초안 확인 → 발송
    ↓  상태: 상담취소 · 선택 일정 해제
```

**메시지 톤 (목업 반영)**

- 부득이한 사정으로 일정을 취소함을 **정중히 사과**한다.
- 접종자에게 **유저웹에서 일정을 다시 선택해 재신청**해 달라고 안내한다.

예시 본문:

```
[VD-IMS] ○○ 선생님입니다.
부득이한 사정으로 ○○ 비대면 상담 일정을 취소하게 되어 진심으로 사과드립니다.
불편을 드려 죄송하며, 유저웹에서 가능한 일정을 다시 선택해 재신청해 주시면 감사하겠습니다.
```

### 4.5 당일 · 상담실

```
[의료진] 오늘 일정 「상담중」 또는 예약 「상담실」 → 상담실 팝업
[접종자 · 비대면 상담 배지] 동의 → 기기 → 대기 → 상담 → 종료
```

**상담실 입장 시각**

- 예약 **확정**된 당일 건은 상담 **시작 15분 전**부터 의료진·접종자 모두 상담실 입장 가능 (기기 확인·대기).
- **시작 시각 ~ 슬롯 종료(30분)** 구간은 상태 **상담중**, 상담실 입장 버튼 핑크 강조.
- 15분 전 ~ 시작 직전은 상태 **예약확정** 유지, 입장 버튼만 활성 (접종자 입장 여부에 따라 핑크/회색).

**상담실 레이아웃 (목업)**

| 영역 | 내용 |
|---|---|
| 좌 | 환자 요약 + 전사 / SOAP / 메모 (남은 세로 공간 채움) |
| 중 | 화상 상담 (WebRTC 목업) · 음소거·카메라·화면공유·종료 |
| 우 | **자가체크 결과** → **AI 분석** 세로 1열 · 팝업 높이 내 스크롤 |

**헤더 액션**

- **상담기록 다운로드** (로컬) · 닫기
- VD-IMS 새 탭·헤더 「상담 종료」는 목업에서 **제거**. 세션 종료는 화상 영역 **종료**로 처리.

## 5. 알림톡

| 유형 | 시점 | 비고 |
|---|---|---|
| 예약요청 | Case B — 의료진 요청 직후 | 일정 선택 URL |
| 예약확정 | 의료진 확정(예약 확정 메시지 발송) 직후 | **비대면 상담 접속 URL** |
| 당일 리마인드 | 상담 시작 **1시간 전** | 동일 접속 URL |
| 예약 취소 | 의료진 「예약 취소」발송 시 | 사과 + 재신청 안내 |

- Case A 신청 직후 예약요청 알림톡 **없음**.
- 발송 주체: **RTMC** (자체 서비스 가정).
