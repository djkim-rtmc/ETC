## 2. 데이터·개인정보

### 확정
- KOI 표시: **마스킹 성명 · 연령대 · 성별** + 식별은 `user_id`/`case_id`
- 연락처·접종·AI 원문: KOI **미전달**. 알림톡은 RTMC
- 동의/계약 문구에 위 표시 항목 반영 필요 (법무)

### 상담기록 (확정)
- **RTMC 서버에 상담기록 본문 미보관**
- 비대면 상담 웹에서 정리된 기록 → **로컬 다운로드만**
- **KOI가 결과를 서버에 저장하는지와 무관** — RTMC 연동은 상태·URL·알림톡만
- RTMC 보관: **상태 · 일시 · staff_id · 처리 이력** 등 연계 메타만

## 3. 의료진 접속 (확정)

**SSO + JIT upsert** (`전체_프로세스_제안.md` §6).

- VD-IMS 계정 → 새 탭 KOI, 해당 의료진 정보 우선 노출
- 예약관리: **본인 기본 + 기관 전체 조회**
- JIT 항목: ID·성명·기관·역할·사용상태

---

## 4. 상태·알림톡 (확정 요약)

- 예약대기(Case A) = **접종자 신청 완료**
- `session_url` = **비대면 상담 접속 URL** (예약확정·당일 리마인드 동일)
- 당일 리마인드 = **1시간 전**
- 트리거 = **발송 요청 API** (상태 콜백과 분리)
- 상담 완료 알림톡 = **미발송** → 웹 **완료 팝업**

### KOI 논의만 (문서 미확정)
- **재요청 · 일정변경** — 프로세스 확정값에 넣지 않음
