## 포함 화면 (첨부 반영)

| 사이드바 | 화면 | 첨부 대응 |
|---|---|---|
| **자가체크** | 자가체크 내역 목록 | ✓ 목록·필터·AI Level·비대면 상담 상태 |
| (행 클릭) | 자가체크 내역 상세 | ✓ 접종정보·탭·AI 분석·비대면 상담 3단 |
| **비대면 상담** | 비대면 상담 대시보드 | ✓ KPI·신청 목록·스케줄(기존 UI) |
| **알림** | 의료진 알림 | ✓ Level 3·4 알림 카드 |
| **유저웹** | 유저웹 자가체크 결과 | ✓ Level 1~4 모바일 UI · 비대면 상담 신청 |

---

## 1. 자가체크 내역 (목록)

| 요소 | 설명 |
|---|---|
| 날짜·검색·AI 분석·비대면 상담 필터 | 첨부 화면과 동일 |
| 테이블 | 체크박스, 바코드, 자가체크 4칸, 통증정도, AI Level, 비대면 상담 상태 |
| ✎ 아이콘 / 성명 클릭 | 상세 이동 |

---

## 2. 자가체크 내역 상세

| 영역 | 설명 |
|---|---|
| 접종 정보 | 성명·연락처·백신·바코드 등 |
| 탭 | 자가체크 · 만족도 조사 · **AI 분석 결과** · **비대면 상담** |
| AI 분석 | 회차별 Level·증상·SHAP (기존 목업) |
| 비대면 상담 탭 | **접수(요청 버튼)** · **처리 이력** · **결과** 3단 |

### 비대면 상담 탭 (현재 UI — v2 수정 전)

| 패널 | 현재 동작 (v2 목업) | v2 방향 (예정) |
|---|---|---|
| 접수 | 접수 상태·일정 정보 + **상담 요청 메시지** | **비대면 상담 요청** → KOI URL + 알림톡 |
| 처리 이력 | 비대면 상담 진행 타임라인 + **상담 현황 보러가기** (KOI) | KOI staff 페이지 연동 |
| 결과 | 상담 완료 시 처치 의견·**상담 결과 상세보기** 팝업 | KOI 콜백 (상담 요약·처치 의견) |

---

## 3. 의료진 알림

Level 3·4 자가체크 알림 (비대면 상담와 별개). 알림 클릭 → 해당 접종자 상세.

---

## 4. 유저별 자가체크 결과 (유저웹 미리보기)

| 요소 | 설명 |
|---|---|
| Level 전환 | Level 1~4 결과 UI |
| 모바일 UI | 증상 슬라이더·AI 안내 |
| 비대면 상담 신청하기 | 클릭 시 **KOI 일정 선택 페이지**로 이동 (`booking_url`) — RTMC에서 일정 미선택 |

---

## 5. v2 프로세스 수정 예정 항목

아래는 **아직 기존 UI**이며, 협의된 v2에 맞춰 순차 수정합니다.

| 항목 | v2 방향 |
|---|---|
| 비대면 상담 탭 일정 선택·확정 | **KOI**로 이전 (VD-IMS에서 제거) |
| 비대면 상담 대시보드 스케줄 CRUD | **KOI** 메뉴 연동 (`staff_id`) |
| 비대면 상담 상태값 | KOI 콜백 (상담요청·예약대기·예약확정…) |
| 유저웹 신청 | ✅ 반영 — KOI `booking_url`로 이동 (RTMC 내 일정 선택 제거) |
| AI 탭 | **비대면 상담 요청** 버튼 추가 (건당) |

---

## 6. 데모 시나리오 (현재 목업)

1. **자가체크** → 임재준( Level 4 ) 상세
2. **AI 분석 결과** 탭 확인
3. **비대면 상담** 탭 → 「상담 요청 메시지」→ 모달 (기존)
4. **알림** → Level 4 알림 → 상세
5. **유저웹** → Level 4 → 「비대면 상담 신청하기」→ KOI 일정 선택 페이지(새 탭)
