# 빔스 로그인 2차 인증 적용 기준

작성 기준일: 2026-10-13

기관회원 로그인 2차 인증은 이메일 인증으로 한다. 적용 대상은 빔스와 CMS다. 기관에 지급한 태블릿을 빔스에 등록하면, 그 태블릿의 미란다 로그인은 아이디·비밀번호만으로 허용한다.

## 1. 빔스·CMS 이메일 2차 인증

- 인증번호는 6자리이며 5분간 유효하다.
- 5회 오입력 시 인증만 처음부터 다시 받는다. 계정 잠금과는 별도이다.
- 재발송은 60초 간격, 최대 3회다.
- 로그인에 성공한 기기는 30일간 기억할 수 있다.
- CMS 계정에도 동일하게 적용한다. CMS 접속은 사내망 또는 VPN만 허용한다.

### 1.1 이메일 등록

- 이메일이 없는 계정은 기능을 켠 날부터 1개월간 로그인을 허용하고 등록을 안내한다.
- 유예 종료일은 날짜로 고정해 공지한다. 그 다음 날부터 이메일이 없으면 로그인을 차단한다.
- 이메일은 본인 등록과 기관 관리자 대리 등록을 함께 허용한다.
- 해당 주소로 인증이 끝난 뒤에만 저장한다.

### 1.2 이메일 변경·계정 정리

- 소속 계정 이메일 변경은 기관 관리자가 한다.
- 기관 관리자 본인 계정은 RTMC 운영이 유선으로 소속을 확인한 뒤 변경하고, 변경 이력을 남긴다.
- 퇴사자는 이메일 변경 대신 계정을 비활성화한다.

### 1.3 발신

- 발신 주소는 `no-reply@회사도메인`을 사용한다.
- 제목은 `[빔스] 로그인 인증번호`로 한다.
- 본문에는 인증번호, 5분 유효, 본인이 아닌 경우 비밀번호 변경 안내를 넣는다.

### 1.4 비밀번호 잠금

- 비밀번호 5회 실패 시 10분간 잠근다.
- 인증번호 오입력은 이 잠금 횟수에 포함하지 않는다.

## 2. 미란다 태블릿

미란다헬스케어는 빔스와 같은 계정으로 로그인해야 빔스 데이터를 확인할 수 있다. 접종 현장 태블릿에서 로그인할 때마다 이메일을 확인하지 않도록, 지급 태블릿은 빔스에 등록해 예외로 둔다.

### 2.1 등록 항목

- 기관
- 기기 이름
- 일련번호 또는 앱이 발급한 기기 ID
- 등록일
- 사용 여부

기기 식별은 IP로 하지 않는다. 지급 태블릿은 이동통신망을 사용해 IP가 바뀐다.

### 2.2 로그인 구분

- 미란다가 보낸 기기 ID가 해당 계정 기관의 등록 태블릿이면 아이디·비밀번호만으로 로그인한다.
- 등록되지 않은 기기에서 미란다에 로그인하면 차단한다.
- 빔스는 같은 태블릿의 브라우저로 접속해도 이메일 2차 인증을 적용한다.
- 분실, 교체, 반납 시 빔스에서 해당 태블릿을 사용 중지로 변경하면 즉시 차단한다.

## 3. 적용 순서

1. 발신 주소를 회사 도메인으로 전환한다.
2. 테스트기관을 대상으로 2주 시범 운영한다. 시작 1주 전에 기관에 공지한다.
3. 1인 1계정으로 전환된 기관부터 이메일 2차 인증과 태블릿 예외를 적용한다.

계정 하나를 여러 사람이 쓰는 22개 기관은 전환이 끝나기 전까지 2차 인증과 태블릿 예외를 모두 적용하지 않는다. 등록된 태블릿 예외가 계정 공유를 통과시키기 때문이다.

RTMC 직원의 CS·시연은 실제 기관 계정을 사용하지 않는다. 테스트기관 전용 계정 또는 권한이 최소화된 운영 계정을 사용한다.

## 4. 일반회원

아이디·비밀번호 계정은 새 기기이거나 로그인 수단이 바뀔 때만 PASS로 재인증한다. 매 로그인마다 추가 인증을 요구하지 않는다.

## 5. 접근 제한

- 빔스·제약사 계정은 이메일 2차 인증을 적용한다.
- 해외 IP는 시범 기간 동안 차단하지 않고 접속 기록만 남긴다. 시범 기간 실측에서 해외 IP로 보인 접속이 국내 사용자의 iCloud 비공개 릴레이로 추정되었기 때문이다.
- 해외 접속이 필요하면 기관 관리자가 신청하고, RTMC 운영 책임자 1명이 기간·계정·사유를 기록한 뒤 승인한다.
- 기관별 고정 IP에서만 접속하는 선택 기능은 만들지 않는다.
- 일반회원은 접근 제한 대상에서 제외한다.

## 6. 로그

- 로그인 이력은 접속기록 화면에 탭으로 추가한다.
- 표시 항목은 일시, 계정, 기관, 성공·실패·잠금, IP, 접속 환경, 2차 인증 결과다.
- 구 서버 접속로그 57만 건(2024.04~2026.08)은 일괄 파기하지 않는다.
- 보관 기간 2년이 지난 건부터 파기 이력을 남기고 삭제한다.
