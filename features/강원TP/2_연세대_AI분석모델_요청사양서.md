# AI 분석모델 개발 요청 사양서 (연세대학교 귀중)

> 발신: ㈜리얼타임메디체크
> 과제: AI 기반 백신 이상반응 돌봄케어 서비스 실증(강원 AX 소형 데이터센터 공동활용 지원사업)
> 요청 범위: 자가체크 서술형 응답 구조화, 심각도(Level) 분류, 설명가능 AI, 성능검증, 연속학습, 논문화

---

## 0. 사업 배경

㈜리얼타임메디체크는 예방접종 후 이상반응을 자가체크(4회: 접종 후 3·48·72·168시간)로 수집하고, AI로 심각도를 Level 1~4로 **참고 분류**하는 서비스를 강원권에서 실증합니다. Level은 의료진 판단 보조 정보이며, 원격진료 실시 여부는 모델이 자동 결정하지 않습니다. 귀 대학에는 이 중 **AI 분석모델 연구개발(자가체크 구조화·심각도 분류·설명가능AI)과 sLLM 개발**을 요청드립니다.

**중요 전제**: 접종 전 위험도를 미리 예측하는 방식이 아니라, **자가체크로 실제 신고된 증상을 그 시점에 즉시 분류(트리아지)하는 방식**으로 설계되어 있습니다. 즉 "미래를 맞히는 예측모델"이 아니라 "현재 들어온 데이터를 분류하는 모델"입니다.

---

## 1. 요청 모델 목록 (우선순위순)

| 우선순위 | 모델명 | 핵심 기능 |
|---|---|---|
| ① | 자가체크 구조화 모델(sLLM+RAG) | 서술형 응답 → 구조화 데이터 변환 |
| ② | 심각도 분류(Level 판정) 모델 | 구조화 데이터 → Level 1~4 판정 |
| ③ | 설명가능 AI 모듈(SHAP) | Level 판정 근거를 요인별로 설명 |
| ④ | 성능검증 프레임워크 | 위 모델들의 신뢰성 검증 |
| ⑤ | 연속학습 파이프라인 | 실증 중 신규 데이터 지속 반영 |
| ⑥ | 실증 결과 기반 논문 초고 | 학술적 근거 확보·게재 |

## 2. 모델별 상세 사양

### ① 자가체크 구조화 모델 (sLLM+RAG)

- **목적**: 접종자가 자유롭게 작성한 자가체크 서술형 응답을 AI가 처리 가능한 구조화 데이터로 변환
- **입력**: 서술형 텍스트 (예: "팔이 붓고 열이 나요", "어지럽고 속이 안 좋아요")
- **출력**: 증상 대분류(11종) + 세부 증상(하단 부록 표 참고), 통증/불편감 강도(예: 1~5)
- **모델 방향**: 오픈소스 소형 LLM(LLaMA, Qwen 계열 등) 파인튜닝 + RAG(검증된 증상 목록·기준 문서 검색 기반 응답으로 환각 방지)
- **주의사항**: 서술형 응답이 없는 단순 체크(예/아니오) 케이스도 함께 지원해야 함 — 서술형이 아닌 정형 입력도 파이프라인에 포함 필요

### ② 심각도 분류(Level 판정) 모델

- **목적**: 그 시점까지 누적된 자가체크 데이터로 Level 1~4를 즉시 판정
- **입력**: 증상 대분류·통증강도(①의 출력), 발생시점(3·48·72·168시간 중 해당 회차), 기저질환·알레르기(자가체크 1차에서 별도 수집된 값)
- **출력**: Level 1(관찰) / 2(주의 관찰) / 3(관리군) / 4(고위험군)
- **비고**: 사전 예측이 아닌 사후 분류이므로, 반드시 시계열 딥러닝(LSTM 등)일 필요는 없습니다. Random Forest·LightGBM 등 분류모델로 충분한 성능이 나올 가능성이 있으니, **귀 대학 판단으로 가장 적합한 방법론을 자유롭게 제안**해 주시면 됩니다. 판정 기준(Level별 임계치)은 저희 측 기존 자가체크 데이터(약 15,000건, 3장 참고)로 함께 조정하고자 합니다.
- **성능 목표**: 개발상세계획서상 「AI 모델 성능 목표 달성율」 지표(가중치 20%)의 목표치는 **"달성률 100%"**로 명시되어 있습니다. 다만 이는 절대 수치(예: 정확도 90% 이상)가 아니라, **귀 대학이 세부 모델별로 직접 설정한 목표치 대비 100% 달성**을 의미합니다. 따라서 **본 모델(②)의 구체적 목표 수치(예: Accuracy, F1-Score 목표값)는 귀 대학에서 제안**해 주시길 요청드립니다(참고: 저희 자체 검토 결과 Level 판정과 유사한 이진 분류 문제에서 AUC 0.6대 초반이 나온 사례가 있어, 목표 수치 설정 시 참고 부탁드립니다). 측정은 Accuracy·F1-Score를 산출해 목표치 대비 달성률(%)로 계산하며, **증빙으로 공인기관의 V&V(검증 및 확인) 시험성적서 또는 이에 준하는 외부 시험성적서가 필요**합니다(계획서 성과지표 증빙 요건). 이 부분도 가능하실지 사전에 확인 부탁드립니다.

### ③ 설명가능 AI 모듈 (SHAP)

- **목적**: ②의 Level 판정이 어떤 요인으로 그렇게 나왔는지 의료진이 이해할 수 있게 설명
- **입력/출력**: ②모델과 동일한 입력, 출력은 요인별 기여도(%)
- **활용처**: VD-IMS 의료진 화면에 "이 판정의 근거"로 시각화

### ④ 성능검증 프레임워크

- **목적**: ①②③ 모델의 신뢰성을 정량적으로 검증
- **방법**: 홀드아웃 검증셋 기반 Accuracy·Recall·F1-Score·AUC-ROC 산출, 가능하면 교차검증(Cross-Validation) 결과도 함께 제공
- **산출물**: 검증 결과 보고서(수치+해석) + **공인기관 V&V(검증 및 확인) 시험성적서 또는 이에 준하는 외부 시험성적서**(계획서상 성과지표 증빙 요건 — 가능한 공인기관이 있으신지, 혹은 저희 쪽에서 별도로 알아봐야 하는지 회신 부탁드립니다)

### ⑤ 연속학습(Continuous Learning) 파이프라인

- **목적**: 실증 중 매일 새로 쌓이는 자가체크 데이터를 모델에 주기적으로 반영
- **산출물**: 파이프라인 설계 문서 + 자동화 스크립트(재학습 주기, 데이터 검증 절차 포함)

### ⑥ 실증 결과 기반 논문 초고

- **목적**: 기술 공인 및 국내외 학술지 투고(목표: Vaccines, npj Digital Medicine 등)
- **산출물**: 논문 초고(실증 데이터 기반)

## 3. 데이터 제공 계획

- 리얼타임메디체크가 기 보유한 이상반응 자가체크 데이터 **약 15,000건**(수도권 12년치) 제공 예정
- 실증 기간(10~12월) 중 신규 수집되는 자가체크 데이터도 순차 제공(목표 참여자 200명 × 4회 자가체크)
- 제공 형식: 가명처리된 정형 데이터(CSV/Excel 또는 API), 개인 식별정보 미포함
- 데이터 제공은 **개인정보 처리위탁 계약** 체결 후 진행 예정이며, 목적 외 사용 금지·재위탁 제한 등의 조항이 포함됩니다

## 4. 연동 방식 (제안)

- 개발 단계에서는 리얼타임메디체크가 제공하는 데이터셋으로 오프라인 학습·검증
- 실증 단계에서는 **추론 API** 형태로 결과 반환을 요청드립니다(요청/응답 스펙 예시)

**요청 (VD-IMS → 연세대 모델 API)**
```json
{
  "case_id": "유저 ID",
  "round": 1,
  "structured_text": "팔이 붓고 열이 나요",
  "onset": "3시간",
  "underlying_conditions": ["고혈압"],
  "allergies": []
}
```

**응답 (연세대 모델 API → VD-IMS)**
```json
{
  "case_id": "유저 ID",
  "symptom_category": "전신증상",
  "pain_score": 3,
  "level": 3,
  "shap_factors": [
    {"factor": "통증강도", "contribution": 0.32},
    {"factor": "발생시점", "contribution": 0.21}
  ]
}
```
> 위 스펙은 초안이며, 실제 필드명·구조는 협의 후 확정 예정입니다.

## 부록. 증상 대분류·세부증상 체계 (①③④ 모델 공통 기준)

자가체크 서술형 응답을 구조화할 때(①), Level 판정 입력값으로 쓸 때(②), 아래 11개 대분류·세부증상 체계를 기준으로 삼아주시기 바랍니다.

| 대분류 | 세부 증상 |
|---|---|
| 심폐 | 기침, 가래, 숨참 |
| 심혈관 | 가슴통증, 두근거림, 혈압저하, 다리 부어오름 |
| 신경 | 두통, 어지러움, 수면장애, 기억력 저하, 저림/이상감각, 근력저하 |
| 전신 | 기력저하, 체중감소, 피로, 발열, 근육통, 겨드랑이 통증, 관절통†, 요통†, 목/어깨 결림†, 림프절 부어오름†, 기타 통증 |
| 소화기 | 속쓰림, 복통/위통, 설사, 구역/구토, 소화불량, 가스참 |
| 정신 | 우울감, 불안, 집중력 저하/멍함 |
| 이비인후 | 후각저하, 미각저하 |
| 안구 | 눈충혈, 각결막염, 시력저하 |
| 피부 | 주사부위통증†, 주사부위발적†, 주사부위 단단함†, 멍이 잘 듦†, 얼굴부기†, 탈모, 피부발진, 두드러기, 부어오름 |
| 부인 | 생리불순, 비정상 질출혈 |
| 비뇨 | 성기능 저하, 소변 양상 이상 |

> `†` 표시 항목은 원본 자료에서 강조 표시되어 있던 세부 증상입니다(강조 사유는 저희 쪽에서 확인 중이며, 확인되는 대로 별도 안내드리겠습니다 — 우선 전체 목록을 공유드립니다).
