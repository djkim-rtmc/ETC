# VD-IMS · 유저웹 목업 화면 기능 정의서

> 대상: 개발팀  
> 기준 목업: `개발전달/VDIMS_화면목업.html` (원본 `VDIMS_유저웹_화면목업.html`과 동일)  
> 작성 기준일: 2026-08-26  
> 성격: 클릭 가능한 단일 HTML 목업. 설치·서버 없이 브라우저에서 파일을 열면 동작한다.

---

## 0. 목업 사용 방법

1. `VDIMS_화면목업.html`을 더블클릭하거나 Chrome/Edge에 드래그한다.
2. 왼쪽 메뉴로 화면을 이동한다.
3. 상단 **김의료 / 이의료**로 의료진 계정을 전환한다. 원격진료 목록은 공용, 일정 확정은 본인 담당 건만 가능하다.
4. 유저웹 목업은 메뉴 **유저웹**에서 확인한다. Level 1~4 칩으로 증상 강도를 바꿔 볼 수 있다.

**목업 한계**

- API·DB 연동 없음. 상태는 브라우저 세션 메모리에만 유지되며 새로고침하면 초기화된다.
- 알림톡·세션 URL·엑셀은 발송/다운로드를 흉내 낸다(토스트).
- 전화번호 실조회, 전자서명, 파일 첨부는 없다.

## 1. 제품 원칙 (개발 시 필수)

| 원칙 | 내용 |
|---|---|
| Level은 참고 | Level 1~4는 AI 분류 제안이다. 진단이 아니다. |
| 원격진료 결정은 의료진 | Level로 신청 버튼을 막지 않는다. 전 Level에서 신청 가능하다. |
| 두 진입 경로 | ① 의료진 제안 ② 접종자 신청. 이후 큐는 같다. |
| 공용 큐 + 단독 담당 | 원격진료 목록은 병원 공용. 한 접종자 건은 의사 한 명만 담당한다. |
| 세션 URL 시점 | 일정 **확정 시점**에 세션을 만들고, 확정 메시지에 URL을 넣는다. |
| 개인정보 | 목록·상세의 접종자 이름은 **두 번째 글자 마스킹**(예: 양○순). 유저웹 본인 화면은 실명. |

## 3. 공통 UI

- 좌측 메뉴: 자가체크, 원격진료, 알림, 유저웹(목업용).
- 상단: 의료진 계정 전환(김의료/이의료).
- 모달 헤더 닫기는 `×`. 스케줄 보기 푸터는 「확인」, 스케줄 등록 푸터는 「취소 / 저장」.
- 상태 뱃지·레벨 뱃지·의료진 뱃지 색은 서로 겹치지 않게 둔다.
  - 레벨: 회색(1) → 노랑(2) → 주황(3) → 빨강(4)
  - 원격진료 상태: 파랑(요청 접수) · 보라(일정 미응답) · 하늘(일정 확정) · 초록(진료 중) · 남색(완료)
  - 의료진: 김의료 분홍, 이의료 청록
- 유저웹만 운영 서비스와 같은 **파란색** 톤을 쓴다. 의료진 화면은 분홍 톤.

## 4. 자가체크 내역 (의료진)

### 4.1 역할

접종 후 자가체크 접수 건을 검색·필터하고 상세로 들어간다.

### 4.2 검색·필터

- 기간(시작일~종료일), 키워드(성명·증상·로트).
- **AI 분석**: Level 1~4 다중 선택. 선택 개수는 드롭다운 오른쪽 숫자.
- **원격진료**: 해당없음, 요청 접수, 일정 미응답, 일정 확정, 진료 중, 완료, 취소 다중 선택.
- 선택된 조건은 칩으로 노출, 칩 × 또는 초기화로 해제.
- 기간·검색 영역은 흰 배경, AI/원격진료·칩 영역만 회색 배경.
- 회차 필터, 불참 상태는 사용하지 않는다.

### 4.3 목록

- 컬럼: 자가체크 일시, 성명(마스킹, 링크), 제조사, 표준코드, 백신명, 로트, 자가체크 회차 바, 주요 이상반응, 통증정도, AI 분석(Level n), 원격진료 상태, 상세.
- 성명 또는 연필 클릭 시 상세로 이동. 상세의 **원격진료 탭**이 열린다.
- 엑셀 다운로드: 목업은 토스트만.
- 기본 노출 10건.

## 5. 자가체크 내역 상세 (의료진)

### 5.1 헤더·접종 정보

- 성명(마스킹), 나이, 생년월일, Level, 원격진료 상태.
- 연락처는 의료진만 조회(목업은 고정 번호, 「전화번호 보기」는 없음).
- 접종 정보: 백신, 제조사, 로트, 접종일시, 기관 등.

### 5.2 탭: 자가체크

- 구분 | 1~4차 비교 테이블.
- 항목명은 볼드하지 않음. 없음은 `-`.
- 점수는 뱃지. 상태값: 신규 / 해소 / 재발현 / 재해소 / 지속 / 악화 / 완화.
- 1차는 「이전 회차 비교」를 숨긴다. 비교 블록은 자가체크 결과 하단에 둔다.

### 5.3 탭: 만족도 조사 결과

- 만족도 결과 영역. 4차 완료 후 제공되는 화면으로 목업은 안내 문구 수준.

### 5.4 탭: AI 분석 결과

- `!` 표시는 AI 탭에 둔다(원격진료 탭이 아님).
- 회차 칩 1~4차. 보유 데이터만 시계열 표시. 빈 3·4차는 숨김.
- 요약 + Level, SHAP/기여도, 증상 점수 비교(평균 n).
- 보유 데이터 비교: 주의는 분홍, 안정은 청록.
- 약학정보원 부작용 대조는 이전 회차 비교 아래.
- 의료진 알림에서 진입하면 **이 탭이 열린 상태**로 진입한다.

### 5.5 탭: 원격진료

**접수 영역**

- 요청 경로(접종자 신청 / 의료진 제안), 담당 의료진, 선택 일정, 접수 상태.
- 하단 버튼: **진료 요청 메시지**, **진료 확정 메시지**.
  - 활성: 분홍. 비활성: 회색.
  - 접종자가 먼저 신청한 경우 요청 메시지 비활성.
  - 확정은 가예약(요청 접수)일 때만 활성.
- **완료**이거나 **다른 의료진 담당**이면 요청·확정·접속 버튼을 **숨김**.

**연동 영역**

- 세션 ID, 접속 URL, 확정 알림톡 상태.
- 하단에 **원격진료 접속하기**(높이 40px). 완료 시 숨김 또는 비활성.

**처리 이력**

- 상태 흐름을 시간순으로 표시.

## 6. 원격진료 운영 (의료진)

### 6.1 KPI

- 요청 접수, 일정 미응답, 일정 확정, 진료 중.
- 카드 클릭 시 아래 목록을 해당 상태로 필터. 「지금 처리할 일」 영역은 두지 않는다(KPI+목록으로 대체).

### 6.2 확정 일정

- **오늘 / 내일 / 모레**를 한 행 3칸.
- 각 칸 오른쪽 위에 `n건` 뱃지. 카드 전체 건수 뱃지는 없음.
- 하루 최대 3건 표시, **더보기 / 접기**.
- 항목: 시각, 접종자·의료진 뱃지(접종자명 · 의료진명, 의료진별 색), 상세 보기.

### 6.3 목록

- 처음 10건, **10개 더보기**.
- 상태 칩은 「전체 n건」과 목록 **사이**, 왼쪽 정렬.
- 카드 구성:
  - **자가체크**: 아래 줄 맨 앞 Level 뱃지, **이름(나이)** 볼드, `|` 뒤 이상반응. 이상반응은 통증 높은 순 2개, 3개 이상이면 `등`.
  - **예약일정 및 상태**: 제목 오른쪽은 **마지막 상태 변경 시각**. 아래 줄 맨 앞 상태 뱃지, **신청 경로** 볼드 `|` 가예약/확정 일시. 요청 접수→일정 확정 시 시각을 확정 시각으로 갱신.
  - **담당 의료진**: 스케줄과 같은 색 뱃지. 칸은 좁게.
- 우측 버튼은 모두 **상세보기**. 목록에서 확정하지 않고 상세로 이동한다.
- 식별번호(R-088 등)는 목록에 노출하지 않는다.

### 6.4 스케줄 등록하기

- 왼쪽: 월 이동 달력. 셀 안에 등록된 시간이 쌓여 보임.
- 오른쪽: 해당 일의 시간 다중 선택(09~20시, 1시간).
- 안내: 「원격진료가 가능한 일정을 선택해주세요.」
- 푸터: 취소 / 저장.

### 6.5 스케줄 보기

- 탭 순서: **전체 > 내 일정 > 다른 의료진**.
- 안내: 「선택한 일자의 시간대별 일정을 확인할 수 있습니다.」
- 미예약 슬롯 문구: **진료가능**.
- 뱃지: `접종자명 · 의료진명`. 빈 슬롯: `진료가능 · 의료진명`.
- 푸터: 확인.

### 6.6 원격진료 요청 메시지

- 좌: 월 이동 달력(일자 선택).
- 우: 시간 선택 → 그 아래 **접종자에게 발송되는 메시지 (수정불가)** 별도 박스.
- 제목 볼드. 메시지 본문은 수정 불가.
- 푸터: 취소 / 발송.

### 6.7 진료 확정 메시지

- 좌: 월 이동 달력.
- 우 세로: ① 시간 선택 ② **접종자 확정 메시지 (수정불가)** ③ **원격진료 접속 정보**.
- 오른쪽 전체 높이는 왼쪽 달력과 맞춤. 확정 메시지 본문은 내부 스크롤.
- 접속 정보 행(담당, 확정 일정, 세션 ID, 접속 URL) 간격은 좁게.
- 제목 볼드. 푸터: 취소 / 발송.
- 확정 시 세션 URL을 메시지에 포함.

## 7. 의료진 알림

### 7.1 목록

- 운영 중인 알림과 같이 **행 전체 클릭**으로 상세 이동. 행 우측 버튼 없음.
- 클릭 시 **자가체크 내역 상세**로 가고 **AI 분석 결과** 탭이 열린다. 읽음 처리.
- 왼쪽 세로 바 없음. 상태 점:
  - Level 4: 빨강
  - Level 3: 노랑
- **원격진료 세션 시작·완료 알림은 발송하지 않는다.**
- 문구 예: `Level 4 즉시 확인이 필요한 자가체크입니다`, `Level 3 확인이 필요한 자가체크입니다`.
- 필터: 전체, 미확인, Level 4, Level 3. 모두 읽음.

## 8. 유저웹 (접종자)

운영 자가체크 결과 화면을 기준으로 한다. 색은 **파랑**.

### 8.1 자가체크 결과

- 헤더: 뒤로 / 자가체크 결과 / 메뉴.
- 김대중님 1차 결과, 병원, 백신.
- 증상 바(숨참, 두근거림 등). 「전체 평균보다 높습니다」는 적갈색.
- 안내: 접종 후 2–3일 고열 등 지속 시 진료.
- **모든 Level에서 「원격진료 신청하기」를 노출**한다. 신청 여부는 접종자 선택.
- 그 아래 AI 리포트 배너(이상반응 헬스케어 서비스 보기).
- 접종 후 경과(1차 펼침, 2~4차 진행전), 나의 기저질환.

### 8.2 신청 이후 버튼 영역

신청 버튼 자리를 **상태로 교체**한다.

| 상태 | 노출 |
|---|---|
| 미신청 | 원격진료 신청하기 |
| 요청 접수 | 요청 접수 + 가예약 일시 |
| 일정 확정 | 일정 확정 + 일시 + 접속하기 |
| 진료 중 | 진료 중 + 접속하기 |
| 완료 | 완료 |
| 취소 | 다시 원격진료 신청하기 |

### 8.3 의료진 선택 바텀시트

- 신청하기 탭 → 아래에서 의료진 목록.
- 의료진이 먼저 제안한 건은 이 단계를 건너뛴다.

### 8.4 일정 선택 바텀시트

- 거의 전체 높이. 월 이동 달력.
- **선택 불가 일자 비활성**: 오늘 이전, 해당 의료진 스케줄 없음, 해당 일 슬롯이 모두 예약됨.
- 가능 일자는 점 표시. 시간은 한 줄 최대 4개.
- 선택하기 → 신청 완료 팝업. 일시 포함. 안내: 「원격진료 일정이 확정되면 접속정보가 메시지로 발송됩니다.」

**구현 참고**: 모바일 웹에서 바텀시트 가능. 일정 시트는 높이가 커서 풀시트(또는 추후 페이지)가 적합하다. 목업은 바텀시트로 유지.

## 9. 상태 정의

| 상태 | 의미 |
|---|---|
| 해당없음 | 원격진료 미진행 |
| 요청 접수 | 접종자 신청 또는 가예약 |
| 일정 미응답 | 의료진 제안 후 접종자 미선택 |
| 일정 확정 | 의료진이 확정, URL 발급 |
| 진료 중 | 세션 진행 |
| 완료 | 진료 종료. 재접속 불가 |
| 취소 | 취소 |

담당 잠금: 요청 메시지 발송 또는 접종자 신청을 맡은 의료진이 담당. 다른 의료진은 해당 건의 요청/확정/접속 액션을 볼 수 없다.

## 10. 업무 흐름

```
[의료진 제안] 상세 → 스케줄 확인 → 요청 메시지 발송
        → 접종자 일정 선택(가예약) → 확정 메시지(URL) → 진료 → 완료

[접종자 신청] 결과 화면 신청 → 의료진 선택 시트 → 일정 시트
        → 가예약(요청 접수) → 의료진 확정 메시지(URL) → 진료 → 완료
```

## 11. 개발 시 목업과 실구현 차이

| 목업 | 개발 |
|---|---|
| 단일 HTML, 로컬 상태 | API·권한·감사 로그 |
| 알림톡 토스트 | 실제 알림톡/푸시 템플릿, 실패 재처리 |
| 세션 URL 고정 문자열 | 확정 시 연계기관 세션 생성 |
| 유저웹이 의료진 콘솔 메뉴에 있음 | 유저웹은 별도 도메인/앱. 메뉴에서 분리 |
| 김대중 고정 샘플 | 로그인 접종자 데이터 |
| 엑셀 토스트 | 필터 조건 반영 다운로드 |

관련 문서: `요구사항 정리/1_VDIMS_유저웹_개발요구사항정의서.md`, `2_연세대_AI분석모델_요청사양서.md`, `3_원격진료연계_요청사양서.md`.

## 12. HTML 공유

| 항목 | 경로 |
|---|---|
| 전달용 목업 | `개발전달/VDIMS_화면목업.html` |
| 작업 원본 | `VDIMS_유저웹_화면목업.html` |

- 파일 하나면 된다. 이미지·라이브러리 의존 없음.
- 메일/메신저 첨부 또는 공유 폴더에 이 파일을 두면 된다.
- 팀원은 브라우저로 열기만 하면 된다.
