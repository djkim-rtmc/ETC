## 1. 범위

### 이번에 그리는 것 (신규·변경)

> **기준:** 실제 Vd-IMS 화면 구조(계정관리·계정상세 팝업·계정생성·병원프로필·계정프로필)를 그대로 따르고, 구축형 필드만 추가한다.

| ID | 화면 | 유형 | 구축형 추가 |
|----|------|------|-------------|
| VI-04 | 병원 프로필 | 기존 + 추가 | **질병청 Usrid/Pwd** |
| VI-06 | 접종내역 목록 | 변경 | 전송상태·재전송·선택 전송 |
| VI-07 | 접종내역 상세 (팝업) | 기존 + 추가 | 예진의사·전송상태·실패사유·PII TTL·재전송 이력 |

> 계정 관리·계정 상세·계정 생성·계정 프로필은 **기존 화면을 사용**하되, 아래 필드 라벨만 변경한다.

### 계정 필드 라벨 변경 (구축형)

| 기존 | 변경 | IR24 | 비고 |
|------|------|------|------|
| 이름 | **예진의사 성명** | `exmdtrnam` | 병원 계정 생성·상세에서 라벨 교체 |
| (추가) | **접종자 정보** | `injnam` | 계정 생성·상세에 필드 추가 |

### 핵심 결정 (실제 구조 반영)

- **질병청 기관 자격(Usrid/Pwd)은 계정이 아니라 「병원 프로필」(기관 단위)에 둔다.**
- 계정 「이름」은 별도 유지하지 않고 **예진의사 성명**으로 대체한다.
- **접종자 정보**는 계정에 별도 필드로 두고, 접종 확정 시 IR24 `injnam`에 주입한다.

### 이번에 그리지 않음

로그인, 계정관리/상세/생성/프로필 UI(기존 유지·라벨만 변경), 통계·대시보드, 백신 마스터, 승인 워크플로

## 2. 권한 계층 (확정)

```
보건소 최고관리자
  └─ 병원 관리자  ← 병원 프로필에 질병청 Usrid/Pwd, 하위 계정·재전송
        ├─ 의사     ← 예진의사 성명 · 접종자 정보
        └─ 간호사   ← 접종자 정보 (예진의는 의사 계정에서)
```

| 역할 | 계정 생성 | 질병청 ID/PW | 접종내역·재전송 | 계정 필드 |
|------|-----------|--------------|-----------------|-----------|
| 보건소 최고관리자 | 병원 관리자 | 조회(마스킹) | 병원 범위 조회 | — |
| 병원 관리자 | 의사·간호사 | **병원 프로필에서 입력** | **재전송** | — |
| 의사 | — | — | 조회(+정책 시 재전송) | 예진의사 성명·접종자 정보 **필수** |
| 간호사 | — | — | 조회 | 접종자 정보 **필수** |

## 3. 화면별 요약

### 계정 생성·상세 (기존 화면 · 라벨 변경만)
**기존:** 아이디, 비밀번호, 비밀번호 확인, ~~이름~~, 전화번호, 권한 설정, 기관명  

| 필드 | 필수 | IR24 | 비고 |
|------|------|------|------|
| **예진의사 성명** | ● (의사 등) | `exmdtrnam` | 기존「이름」라벨 대체 |
| **접종자 정보** | ● (의사·간호사) | `injnam` | 신규 필드 |

### VI-04 병원 프로필 (기존 + 구축형 추가) ★
**기존:** 프로필 이미지, 병원명, 대표자명, 사업자번호, 주소, 팩스, 전화번호, 전화번호 공개  
**구축형 추가:**

| 필드 | 필수 | 비고 |
|------|------|------|
| 질병청 기관 ID (Usrid) | ● | IR24 `Usrid` |
| 질병청 기관 PW (Pwd) | ● | 암호화 저장, 화면 마스킹 |
| (권장) 연결 테스트 | △ | 저장 후 로그인 검증 |

- 질병청 자격은 **기관 단위**이므로 계정이 아닌 병원 프로필에 둔다.

### VI-06 접종내역 목록
**기존:** 접종일시 · 성명(마스킹) · 감염병명 · 유/무료 · 백신명 · 로트번호 · 자가체크 · 연계 진료 · 수정 아이콘 / 기간·검색어 필터 / 엑셀다운로드 / 페이지네이션

**구축형 추가:**

| UI | 내용 |
|----|------|
| 전송상태 드롭다운 | 검색 영역 **맨 앞** (전체/미전송/전송실패/전송완료) |
| 전송상태 컬럼 | `미전송` / `전송실패` / `전송완료` |
| 행 체크박스 | 목록 **맨 앞** 컬럼 + 헤더 전체선택 |
| 선택 전송 버튼 | **엑셀다운로드 앞** · 선택 건 일괄 재전송 · 선택 0건이면 비활성 |
| 표시 | RRN **비표시** |

**일괄 재전송 플로우**

1. 전송상태 = `전송실패` 필터
2. 헤더 체크박스로 표시된 전체 선택 (필터로 숨겨진 행은 선택 해제)
3. [선택 전송] → 선택 건 Register 일괄 재호출

- **전송완료 건은 체크박스 비활성** (PII 파기됨 → 재전송 불가)
- 개별 건은 수정 아이콘 → 접종내역 상세 팝업(VI-07)

### VI-07 접종내역 상세 (팝업)

기존 팝업(성명·생년월일·핸드폰 / 제조사·백신명·로트·유효기간 / 접종일시·장소·방법·부위·용량) 구조를 유지하고, 아래 영역을 **추가**한다.

| 영역 | 내용 |
|------|------|
| 전송상태 뱃지 | 제목 **접종내역 상세** 옆에 뱃지로 표시 |
| 예진의사 | 환자 정보 영역에서 **기저질환 오른쪽**에 표시 (`exmdtrnam`) |
| 실패 사유 | `last_error`·`errmsg` — **전송실패일 때만** 표시 |
| 재전송 이력 | 시각·결과·메시지 · 건수가 많으면 **영역 내 스크롤** |

**버튼 노출 규칙**

| 전송상태 | 버튼 |
|----------|------|
| 미전송 · 전송실패 | [취소] [**재전송 실행**] |
| 전송완료 | [**닫기**] 만 노출 (하단 실패사유·PII·재전송 이력 영역도 숨김) |

- 재전송 = 동일 건 Register 재호출
- **PII 잔존(실패 TTL 내)일 때만 가능** — 만료 시 “보호자 재입력 후 재접종 프로세스” 안내

## 4. 데이터·정책 연동

| 규칙 | 내용 |
|------|------|
| 개인정보처리자 | 보건소 / 회사 = 수탁·운영 |
| 질병청 자격 | **병원 프로필(기관 단위)**에 입력 (병원별) |
| 의료진명 | **Vd-IMS 계정**의 예진의사 성명·접종자 정보 → 접종 확정 시 자동 주입 |
| 성공 전송 | PII 즉시 파기 |
| 실패·미전송 | **당일(TTL)만** PII 보관 → 그 안에서만 재전송 |
| 의료진 UI | RRN·주소 비표시 |
