## 1. 전제

1. **병원 OCS 연동은 하지 않는다.** OCS의 `TPATIENT` / `TTPREVEN` 역할은 구축형 테넌트 DB가 수행한다.
2. **개인정보처리자 = 보건소**, 회사(RTMC) = 처리수탁·운영. 주민번호·주소 등 민감정보는 보건소 공공클라우드에만 두고, 질병청 등록 ACK 후 파기하는 정책을 기본으로 한다.
3. **의료진 IR24 필수값**은 Vd-IMS **계정 관리(계정 상세)** 화면에서 계정 정보와 함께 입력·관리한다.
4. 질병청 전송 시 조립 객체는 현행 기준 `VcnRegInfo` → `VcnRegService.Register` 이다. (차세대 WEB·JWT는 Adapter 교체 예정)

### UX 가이드

- 권한 = `접종 의료진` 인 계정 생성·수정 시 **접종자 성명** 미입력 시 저장 불가.

## 7. 질병청 전송 조립 순서 (논리)

```
1) 병원 계정 질병청 자격(Usrid/Pwd) + 기관코드·명
2) 피접종자 상시정보(family_member) + 임시 PII(subject_pii_temp)
3) 보호자·동의·연락처
4) 로그인/지정 의료진(staff_account → injnam, exmdtrnam)
5) 접종 확정 데이터(vaccination_record + 백신조회)
6) VcnRegInfo 조립 → Register
7) 결과 반영(send_yn, reg_status) → 접종내역 표시 / 재전송
8) 성공 시 PII 파기 로그 (실패·미전송은 TTL 정책)
```
