| 항목 | 내용 |
|------|------|
| 작성일 | 2026-08-18 |
| 목업 | `유저웹_구축형_상시저장_목업_v2.html` |

---

## 1. 모델

- **처리자**: 보건소  
- **저장**: 보건소 공공클라우드 DB **암호화 저장(상시)**  
- **회사(RTMC)**: 수탁·운영  
- SNS / PASS 인증 후 **회원가입 시** 주민번호·주소 수집  
- **가족 추가 시**에도 동일하게 필수 정보 수집·암호화 저장  
- 접종 당일: 저장된 대상으로 **접종 QR만 발급** (PII 재입력 없음)
