# 구축형 목업 — 개발팀 공유 안내

CSS·JS가 HTML 안에 들어 있어 **별도 빌드·설치 없이** 동작합니다.

## 포함 파일

| 파일 | 내용 |
|------|------|
| `Vd-IMS_구축형_추가화면_목업.html` | Vd-IMS 추가 화면 (병원 프로필·접종내역·상세 팝업) |
| `유저웹_구축형_추가화면_목업.html` | 유저웹 v1 (접종당일 임시입력) |
| `유저웹_구축형_상시저장_목업_v2.html` | 유저웹 v2 (상시저장) |
| `mockup-server.js` | 로컬 미리보기 서버 (선택) |
| `목업_실행.bat` | Windows 원클릭 실행 (선택) |

## 방법 A — HTML만 열기 (가장 간단)

1. zip 압축을 풀거나 폴더를 받습니다.
2. `Vd-IMS_구축형_추가화면_목업.html`을 Chrome / Edge에서 더블클릭합니다.
3. 상단 `VI-04` / `VI-06` / `VI-07` 버튼으로 화면을 전환합니다.

동일하게 유저웹 HTML도 더블클릭으로 확인할 수 있습니다.

## 방법 B — 로컬 서버 (링크 이동까지 한 번에)

Node.js 18+ 가 필요합니다. (npm 설치 불필요)

```bat
목업_실행.bat
```

또는

```bash
node mockup-server.js
```

| URL | 목업 |
|-----|------|
| http://localhost:8123/ | 유저웹 v1 |
| http://localhost:8123/v2 | 유저웹 v2 |
| http://localhost:8123/vims | **Vd-IMS** |

## Vd-IMS에서 확인해 볼 인터랙션

- **VI-04** 병원 프로필 — 질병청 Usrid / Pwd 입력 영역
- **VI-06** 접종내역 — 전송상태 필터, 행 선택, **선택 전송**
- **VI-07** 접종내역 상세 팝업
  - 제목 옆 **전송상태 뱃지**
  - 환자 정보 행의 **예진의사**
  - 전송실패 시 실패 사유 · 재전송 이력(스크롤)
  - 미전송/전송실패 → `재전송 실행` / 전송완료 → `닫기`
  - 화면 라벨의 `미전송` · `전송실패` · `전송완료` 버튼으로 상태 전환 미리보기
  - VI-06 목록 `✎` 클릭 시 해당 행 상태로 팝업 열림
