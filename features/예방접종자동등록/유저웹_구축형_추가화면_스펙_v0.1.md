## 2. 진입·데이터 규칙

| 규칙 | 내용 |
|------|------|
| 진입 | 병원 비치 QR → 유저웹 → 로그인 → **UW-02** |
| 본인 | UW-04 → UW-07 |
| 가족 | UW-05 → (기존 선택 또는 UW-06) → UW-07 |
| 식별번호 | 13자리 / 7자리(신생아) / 외국인등록번호 |
| 7자리 시 | 보호자 주민(또는 외국인등록)번호·쌍둥이 **필수**, HepB1·BCG만 안내 |
| 관계 | 필수 (`본인/부/모/자/기타`) — 본인 경로면 `본인` 자동 |
| 우편번호 | 주소 저장 시 자동 조회 |
| 접종자 QR | **TTL 강제 없음** / 성공 전송 후 PII 즉시 파기·실패 시 당일 파기 |
| 연결키 | 파기 후 이력은 **별도 ID** |
| 의료진 | RRN 미표시 (미란다 측) |

## 3. 화면별 요약

### UW-01 로그인
- 기존 유지: 카카오 / 네이버 / 회원 로그인·회원가입
- PASS: 로그인 버튼 추가 **없음**. **일반 회원가입 시 PASS 본인인증** (기존 흐름)

### UW-02 오늘 접종 확인 (병원 QR 스캔 → 로그인 후)
- 제목: 오늘 예방접종을 진행하시나요?
- 안내 문구: 필수 정보를 입력하면 접종용 QR이 발급됩니다.
- 안내 카드: 입력한 정보는 질병관리청 예방접종정보 등록 후 즉시 삭제 됩니다.
- 하단 좌우 버튼: **아니오** | **네, 오늘 접종합니다**
- 네 → UW-03 / 아니오 → 기존 홈

### UW-03 대상 선택
- 제목: 누가 접종하나요?
- 안내: 오늘 접종하시는 분을 선택해주세요
- 본인 (가입 회원) / 가족 (자녀)

### UW-04 본인 입력
- 안내: 질병관리청 예방접종 등록을 위한 필수 정보입니다. 모두 입력해주세요
- **내/외국인 선택**: 주민번호 13자리 / 외국인등록 (신생아 7자리는 본인 화면에서 제외)
- 주민번호(또는 외국인등록번호), 주소(+우편번호 자동)
- 관계 = `본인` 자동
- 다음 → UW-07

### UW-05 가족 선택
- 등록된 가족 목록 + **가족 추가**
- 가족 추가 안내: 새로운 가족을 추가할 수 있어요
- 선택 후 → 해당 가족 PII 입력(UW-04와 동일 패턴) 또는 UW-06
- **카피 톤**: 서비스 내 문구는 **해요체(~요)** 통일

### UW-06 신규 가족
- 안내: 질병관리청 예방접종 등록을 위한 필수 정보예요. 모두 입력해 주세요
- 이름 → **주민등록번호 / 신생아** 선택 + 식별번호 입력 (신생아 시 보호자 번호 노출)
- 생년월일 필드 **삭제** (7자리·13자리에서 파생)
- 성별
- **관계** · **쌍둥이 구분** 한 줄 좌우
- 식별번호 유형 별도 필드 **삭제**
- 주소(+우편번호 자동)
- 버튼: **접종 QR 발급**

### UW-07 접종 QR
- 제목: 접종 QR을 의료진에게 보여주세요
- 안내: 접종 QR 스캔 후 백신 접종이 진행돼요
- QR 하단: {이름} 님 접종 QR (+ 생년월일·성별·관계)
- 별도 ID 배지·안심QR 비교 안내 카드 **삭제**
- TTL 강제 없음 / 전송 성공 시 PII 즉시 파기 (정책은 백엔드)
